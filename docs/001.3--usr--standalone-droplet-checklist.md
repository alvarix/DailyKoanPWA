# Standalone Droplet Deployment — Checklist (Doc 001.3, usr)

Execution checkboxes for `docs/001.2--llm--STANDALONE_DROPLET_DEPLOYMENT.md`. Do not mark a GATE until its command passes.

## Phase 0 — Pre-flight

- [ ] DO account + SSH key registered
- [ ] DNS access for `alvarsirlin.dev`
- [ ] Code on GitHub (or rsync fallback ready)

## Phase 1 — Create droplet

- [ ] Ubuntu 24.04 LTS, 1 vCPU / 1 GB, SSH-key auth only, hostname `dkStandalone`
- [ ] GATE: `ssh root@<STANDALONE_IP> 'uname -a'` succeeds

## Phase 2 — Hardening

- [ ] `alvar` sudo user + `koan` service user created; SSH key copied
- [ ] GATE: `ssh -t alvar@... 'sudo -v && echo SUDO_OK'` -> password prompt (alvar's own) -> SUDO_OK (before touching sshd; `-n` never passes on stock Ubuntu)
- [ ] Password SSH disabled via `sshd_config.d/99-hardening.conf`
- [ ] GATE: `sshd -t` clean, then `systemctl reload ssh`
- [ ] UFW: OpenSSH, 80, 443 allowed BEFORE `ufw enable`
- [ ] GATE: `ufw status` shows all three
- [ ] unattended-upgrades enabled

## Phase 3 — Packages + code

- [ ] `nginx certbot python3-certbot-nginx python3-venv python3-pip git sqlite3` installed
- [ ] Code at `/opt/dailykoan` (git clone or rsync; excludes honored: no `.pem`, no `subscriptions.db`)
- [ ] venv + `pip install -r requirements.txt`
- [ ] `init_vapid.py` (fresh keys OK at launch), `init_db.py`, `init_icons.py` run
- [ ] `chmod 600 vapid_private.pem`
- [ ] GATE: all three artifacts exist (`vapid_private.pem`, `subscriptions.db`, `static/icon-192.png`)

## Phase 4 — Gunicorn

- [ ] `dailykoan.service` created; `systemctl enable --now dailykoan`
- [ ] GATE: `curl -s http://127.0.0.1:8001/api/today` returns JSON

## Phase 5 — DNS (DuckDNS)

- [ ] DuckDNS subdomain `dailykoan` created and pointed at `<STANDALONE_IP>` (panel or update API)
- [ ] GATE: `dig +short dailykoan.duckdns.org` returns droplet IP (before certbot)

## Phase 6 — nginx (full server block — no Forge here)

- [ ] `sites-available/koan` written; symlinked into `sites-enabled`
- [ ] GATE: `sudo nginx -t` → syntax ok
- [ ] `sudo systemctl reload nginx` (reload, not restart)
- [ ] GATE: `curl -sI http://dailykoan.duckdns.org/api/today | head -1` → 200

## Phase 7 — HTTPS

- [ ] `certbot --nginx -d dailykoan.duckdns.org` succeeded
- [ ] GATE: `nginx -t` + `reload nginx` + `https://.../api/today` → 200
- [ ] GATE: `certbot renew --dry-run` succeeds

## Phase 8 — Daily push timer

- [ ] `dailykoan-push.service` + `.timer` created (`OnCalendar=*-*-* 08:00:00`, UTC; `Persistent=true` understood)
- [ ] `systemctl enable --now dailykoan-push.timer`
- [ ] GATE: `systemctl list-timers` shows next run
- [ ] GATE: manual `systemctl start dailykoan-push.service` → "Sending to 0..." in journal

## Phase 9 — End-to-end + maintenance

- [ ] iOS: Add to Home Screen → open PWA → subscribe → count includes device
- [ ] GATE: test push arrives; tap opens correct koan
- [ ] Off-droplet backup of VAPID key pair made (irreplaceable)
- [ ] Backup procedure uses `sqlite3 .backup`, never raw `cp` of live DB
