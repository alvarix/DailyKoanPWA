# 002.2 — TWEAKS, iteration 2: push title becomes the koan title

## Plain English — what this is

This morning's notification still had a second title-like line: "Daily Koan" (app header) then "From Koan"/a second "Daily Koan" line. The intent of 002 tweak 2 was a bare alert, but iOS always renders at least an app-name header; the SW was falling back to `Daily Koan` for the title, duplicating the look.

Fix: the push payload now sends `title: <koan title>` and the SW fallback is empty. The OS app header stays, but the second line becomes the koan title instead of another "Daily Koan" or the origin subtitle.

The ~1h latency reported is **not reproduced in the server logs**: the 10:00 UTC run computed local time as 05:00 `America/New_York` and sent at that moment. So the server was on time for the configured timezone. Any further delay is phone-side (APNS/Focus/DND/Low Power Mode).

The truncation you saw this morning ("down beside him. Chao-chou...") was the iOS banner display limit, not the payload limit: the current longest koan text is only ~344 raw bytes, and the payload body limit is 750. A sentence ending may still be cut by iOS's visual truncation. Raising the payload limit from 3000 to 750 gives headroom for future longer koans while staying well under the Web Push encrypted-size budget.

## Edge cases considered

1. **Malformed/string payload** — SW used to inject `{ title: 'Daily Koan', body: payload }`. Now it injects `{ body: payload }`, so even a string fallback gets an empty title.
2. **Long koan body** — payload byte limit kept at 3000; ellipsis accounting prevents overshoot.
3. **Stopped mid-broadcast** — `mark_pushed` still runs only after the send loop; a crash before it re-sends rather than silently skipping. Unchanged.
4. **iOS still shows "From Koan"** — the origin subtitle is an OS-level affordance Apple may still render. We cannot remove it from a web push, but the payload-controlled title now carries useful text.

## Decision recorded

- The OS app-header line is acceptable; the payload title line now displays the koan title instead of the app name.
- Latency remains hour-gated by `push_time` + `push_timezone`; no code change until server logs show a late send.

## For dummies

The phone insists on showing "Daily Koan" at the top. We can't stop that. But we can choose what goes on the second bold line. Now that line says the koan title instead of repeating the app name.
