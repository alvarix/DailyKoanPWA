# ADR: Frontend

Status: Accepted (current stack) / Proposed (002 tweaks)
Date: 2026-11-16
Related: docs/002--llm--TWEAKS.md, mockup.html (design reference)

## Context

Daily Koan is a reading app: one koan per view, commentary, verse, a bell to subscribe to push. The
design language (warm paper theme) was fixed in `mockup.html` and ported into the Jinja template during
Phase 1. The product targets iOS Home Screen PWAs (16.4+) — push and install only work from an installed
HTTPS PWA there, which constrains everything below.

## Decision

**Zero build step.** No npm, no bundler, no node_modules. Tailwind CSS, Alpine.js, and HTMX load from CDN;
Flask serves Jinja-rendered HTML. Rationale: the app is one page with light interactivity — a build
pipeline would be permanent infrastructure for zero product value. Trade-off accepted: CDN availability
is a runtime dependency (offline-first covers it — see SW below).

**Server-rendered page + Alpine islands.** `templates/index.html` is rendered by Flask with the koan,
index, and VAPID public key in template context. Alpine (`koanApp()`) handles the interactive corners:
notification bell toggle (subscribe/unsubscribe via `/api/*`), subscribe-state check on load
(`pushManager.getSubscription()`), iOS help visibility. This split — server owns content, Alpine owns
state — is why the 002 mode-switch (proposed) needs the server to pass `mode` into the context rather
than the client guessing.

**Native `<details>/<summary>` for collapsibles.** No JS accordion: keyboard- and screen-reader-accessible
by default, styled with Tailwind group-open caret rotation. Current state: commentary 1 `open`, commentary 2
closed, verse not collapsible. The 002 tweak (proposed) makes all three collapsed by default and wraps the
verse in the same pattern — deliberately recorded there as a product change, not an implementation detail.

**Service worker (`static/sw.js`).** Network-first for navigations with cache fallback (fresh koan when
online, last-known when not); cache-first for static. Push handler with payload fallbacks
(`data.title || 'Daily Koan'`, `data.body || 'A new koan awaits.'` — relevant to 002's bare-alert tweak:
omitting the title is expected to surface the app name as the system title line). `notificationclick`
focuses an existing client at `data.url` or opens one. Cache name `daily-koan-v1` — bump on SW shape changes.

**PWA shell.** `static/manifest.json` + icons generated by `init_icons.py` (placeholder art), served by
nginx directly alongside `sw.js` (also Flask-routed as a fallback). HTTPS is a hard requirement (Web Push
refuses plain HTTP; iOS additionally requires Home Screen install before granting notification permission).

**Design rules.** Near-black on warm paper, saturated neutrals, the calm typography from `mockup.html`;
no emoji, serif for reading text, small caps tracking for labels. All changes keep line length, contrast,
and "closer = lighter" cues consistent with the existing palette.

## Consequences

- One template, one script tag set, one SW file — the entire frontend surface is readable in one sitting.
- Template changes ship with `git pull && systemctl restart dailykoan`; no build cache to invalidate.
- CDN outage degrades styling/interactivity before SW cache is populated; acceptable for a personal PWA.
- The 002 frontend work (mode-aware controls, collapsed defaults, post-`/api/next` refresh) extends this
  file's Alpine island pattern — it does not replace it.
